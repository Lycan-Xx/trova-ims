# Auth Background Image

## Setup Instructions

The auth pages (sign-in and sign-up) expect a background image at this location:
`public/images/auth/auth-bg.jpg`

### How to Add the Image

1. **Find a suitable image** from these sources:
   - Freepik (warehouse, inventory, logistics, office theme)
   - Unsplash
   - Pexels
   - Pixabay

2. **Requirements:**
   - Format: JPG or PNG
   - Size: Recommended 1600x1200px or larger
   - Theme: Warehouse, inventory, office, or logistics related
   - Aspect ratio: Landscape (wider than tall)

3. **Save as:** `auth-bg.jpg` in this directory

4. **Result:** The image will automatically appear on the auth pages with a dark gradient overlay for text readability.

## Example Images

Search for these terms on stock image sites:
- "Warehouse inventory"
- "Logistics management"
- "Office collaboration"
- "Modern warehouse"
- "Supply chain"

Once you've downloaded and placed the image, the auth pages will display:
- Desktop: Image on left (67%), form on right (33%)
- Tablet: Hero section visible but slightly smaller
- Mobile: Hero text above form, image hidden
