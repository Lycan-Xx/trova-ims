# Trova IMS Project Context

## Licensing follow-up

An explicit customer-facing EULA is a future legal and product task. The current
application includes an interim authorized-use notice, but it does not yet include
formal EULA acceptance, terms, or a redistribution enforcement mechanism.

## Desktop diagnostics

Production desktop builds keep the normal console hidden. A technician can open
the main window's DevTools with `Ctrl+Shift+F12`. The shortcut is intentionally
undisclosed in the normal product UI and invokes the native `open_main_devtools`
command. Keep this capability documented for support and release testing.
